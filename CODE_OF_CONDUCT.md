## What the Covenant requires this project to specify

Version 3.0 leaves the reporting mechanism to each community. This is it.

### Reporting

Report a concern privately to the maintainer, **Mohd Saif Hussain**, through
either:

- GitHub private vulnerability reporting on this repository, which works for
  conduct reports as well and keeps the thread private, or
- a direct message to [@MohdSaifHussain](https://github.com/MohdSaifHussain).

Reports are handled privately with the people involved. Expect an
acknowledgement within a week.

**Set your expectations honestly:** this is a personal project maintained by one
person, who is also the only moderator. There is no committee and no appeals
body. If a report concerns the maintainer, GitHub's own
[reporting mechanisms](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
are the escalation path, because a process where the subject of a complaint is
also its only judge is not a process.

### Enforcement

Responses follow the Covenant's enforcement ladder: a private written warning,
then temporarily limited activities, then temporary suspension, then a permanent
ban, chosen according to severity and whether a pattern is established.

### Scope

Applies in all project spaces (issues, pull requests, discussions, commit
messages, code review) and whenever someone is representing this project
elsewhere.
